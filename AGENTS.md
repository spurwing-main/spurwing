# Spurwing public code

This repository contains browser-readable site code. Read the project's
[private README](../private/README.md),
[working rules](../private/AGENTS.md) and
[build guide](../private/BUILD.md) before changing code.
General setup guidance lives in
[webflow-sops](../../webflow-sops/guides/project-setup.md#project-folders-).

Run npm and Git commands from this folder. Reviewed project records belong in
`../private/`; temporary work and raw evidence belong in `../local/`.
Do not commit private records, credentials, correspondence or raw exports here.
Preserve unrelated changes. A local code change does not authorise committing,
pushing, deployment or publication. Use shell/filesystem tools for repository
work; do not use the VS Code UI.
